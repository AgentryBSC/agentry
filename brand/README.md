# Agentry 标志

方案 A「入口」：一道门（也是小写 a 的轮廓），门里站着一个 Agent。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `agentry-logo.svg` | 矢量，透明底 | 首选。印刷、海报、任意放大 |
| `agentry-logo-1024.png` / `agentry-logo-512.png` | 1024 / 512，透明底 | 不支持 SVG 的地方 |
| `agentry-icon-black-1024.png` | 1024，黑底 | 社交头像、App 图标 |
| `agentry-icon-180.png` | 180，黑底 | iPhone 主屏图标 |
| `agentry-favicon.svg` | 矢量，黑色圆角底 | 浏览器标签页图标 |
| `agentry-lockup-dark.png` | 1100×352，深色底 | 标志 + 文字，放在深色背景上 |
| `agentry-lockup-light.png` | 1100×352，白底 | 标志 + 文字，放在浅色背景上 |

- 金色 `#F0B90B`，深色底 `#080807`，文字浅色 `#F6F4EE`
- 文字字体 Geist Semibold
- 小于 24px 时用 `agentry-favicon.svg` 那版（线条更粗），别直接缩小透明底版本
